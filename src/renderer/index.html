本地文件
说明

· 管理并播放本机视频：出于安全仅能访问你指定的根目录，首次使用请先点「更换根目录」选择文件夹

· 仅展示文件夹与视频/音频文件；单击视频/音频调用播放器播放，单击文件夹进入，按 Esc 返回上层；文件较多时底部有分页条（每页 100 项）。

· 「上传文件」：把本机其他位置的视频复制到当前目录（会弹窗选文件）。

· 「新建文件夹」：在当前目录创建子文件夹，方便分类整理。

· 「更换根目录」：重新指定可访问的本地文件夹（历史记录保留）。

· 右键点击文件/文件夹可删除（删除的是根目录内的真实文件，请谨慎操作）。

网盘账号
说明
夸克 / UC / 百度等网盘影视源（JAR 源）播放时需要对应网盘的登录凭据，与 TVBox 一致。
夸克网盘：点「夸克扫码登录」用夸克 App 扫码，登录后自动保存，无需手动复制。
其他网盘：浏览器登录网盘网页 → F12 开发者工具 → 「网络」→ 刷新页面 → 点任意请求 → 「请求头」复制整行 Cookie（形如 __puus=xxx; __pus=xxx; …）→ 粘贴到对应输入框保存。
注意：只粘贴 Cookie 内容本身（不要带「Cookie: 」前缀），且必须是完整的「字段=值; 」组合，单个 token 无效。
未配置 Cookie 时，网盘源详情页照常显示，但播放会快速失败并提示原因。

欢迎使用 YuKi

YuKi 是一个基于 CatVod 架构的影视聚合桌面端，现已整合 Kazumi 规则引擎。

快速上手：

1. 在「设置 → 源设置」粘贴配置地址载入视频源

2. 在「设置 → Kazumi 规则」管理番剧规则源（已内置 3 个默认规则）

3. 在「时间表」查看每日番剧更新

4. 搜索影片后在详情页选择「Kazumi 规则源」播放

5. 收藏影片可追踪观看进度，播放窗口由 mpv 独立承载

本项目不收集任何用户数据。使用产生的数据和缓存应在 24 小时内清除。
