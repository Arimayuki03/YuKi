# ADR-0002：桌面 DRM 播放策略

- 状态：Accepted
- 日期：2026-08-19
- 范围：C1 PC 原生兼容之外的决策，不含实现

## 背景

TVBox/FongMi 配置或 Spider 可能返回 `drm` 元数据。mpv 和当前 Electron 播放链不能据此
自动获得 Widevine、PlayReady 或服务商专有授权。播放用户有权访问的内容仍必须遵守内容
授权、CDM/SDK 许可、账号和地域限制。

## 方案比较

| 方案 | 优点 | 许可、安全与工程约束 | 决策 |
|---|---|---|---|
| Chromium CDM | 可留在桌面 Web 播放链 | CDM 分发许可、Electron 版本绑定、license session/凭据隔离、更新和发布审计均未完成 | 暂不采用 |
| 授权播放器 SDK | 授权边界和厂商支持最清晰 | 需要合法商业授权、原生封装、平台签名、SDK 安全评估和独立首帧矩阵 | 后续首选候选 |
| Android 播放画面转交 | 复用 Android 播放能力 | A4.1 已 No-Go；设备、画面/声音转交、输入、账号和发布复杂度超出 C1 | 不采用 |
| 明确不支持 | 不扩大许可和攻击面，行为可诊断 | 受 DRM 保护的源不能在当前内核播放 | **当前采用** |

## 决策

1. `PlayResult.drm` 原样保留到播放边界，诊断可指出 DRM 类型，但不得记录 license token、
   Cookie、Authorization 或完整短期 URL。
2. 当前 C1 产品在启动 mpv 前返回明确的“当前桌面播放器不支持该 DRM”错误；不得把 URL
   存在、解析器返回或播放器进程创建当作成功。
3. 不实现 CDM 提取、license 请求拦截/伪造、密钥导出、解密绕过、账号/地域限制规避，
   也不提供未授权 DRM 播放路径。
4. DRM 不属于 P5/C1 退出条件；本 ADR 只关闭决策任务，不扩大产品支持声明。

## 重新评估条件

仅当同时具备内容/SDK/CDM 的书面授权、发布许可、安全评审、敏感凭据隔离方案、可维护的
平台集成，以及正常/异常/超时/取消/首帧端到端测试后，才新建立实施 ADR。优先评估授权
播放器 SDK；任何新方案仍不得以绕过 DRM 为目标。
